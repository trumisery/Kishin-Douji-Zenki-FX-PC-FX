ABOUT THIS RELEASE

This English fan translation adds subtitles to the game's Japanese spoken
dialogue and songs, along with English menu and interface text.

Based on the Japanese Redump release:
  Kishin Douji Zenki FX - Vajra Fight (Japan)
  Redump disc record: http://redump.org/disc/67251/


GETTING STARTED

Use the original, unchanged CUE file:

  Kishin Douji Zenki FX - Vajra Fight (Japan).cue

No updated or renamed CUE is required. The original track filenames and
disc layout are retained, so the filenames still include "(Japan)" even
though the game has been translated.

1. Keep the CUE file and all 20 BIN tracks together in the same folder.
2. For PC-FX emulation, open the CUE file with your emulator or core.
   Use the BIOS and settings required by that emulator.
3. For a disc intended for real PC-FX hardware, load the CUE in your
   disc-writing software so that the complete track layout is preserved.

Open or burn the CUE rather than an individual BIN track. Keep the track
filenames unchanged so the CUE can find them.


WHAT WAS CHANGED

- Added English subtitles to story dialogue, including scenes that
  originally had Japanese speech without any subtitles.
- Subtitled the opening animation/song and both ending songs.
- Translated menus, character-selection names and the selection prompt.
- Translated load-screen chapter titles and player HUD names.
- Added English subtitles for opening story text and applicable stage
  information while retaining the original artwork.
- Added an optional infinite-health code for playing through the game.
- Improved subtitle coverage, placement, cleanup and HUD restoration.
- Corrected character-selection text that reverted to Japanese, missing
  dialogue captions, and previously reported display and stability issues.

The original Japanese voices and music are retained. The title screen and
gameplay background artwork are preserved. Repeated nonverbal combat grunts
are not captioned.


SUBTITLE APPEARANCE AND PLACEMENT

Subtitles use bold white lettering with a complete black outline and a
transparent background. There is no solid text box.

Story conversations use the lower screen area beneath the characters,
beside the CREDITS counter. Boss names and health bars are temporarily
hidden during these conversations and restored afterward.

Other spoken lines use the lower area when the boss display is absent,
or appear above it while it is present. Movies and songs use placements
suited to their scenes.

Version 1.8 improves the font with proportional spacing and intact letter
shapes, including wide letters such as W and M. Letters have enough room
for their full shapes and outlines. Subtitle wording and timing are
unchanged from v1.7.


CHEAT CODES

Infinite health - added for this translation

At the title screen, enter the following with player 1:

  UP, UP, UP, DOWN, DOWN, DOWN, LEFT, RIGHT, LEFT, RIGHT

Release each direction between presses.

- Two flashes/chimes indicate infinite health is ON.
- One flash/chime indicates infinite health is OFF.
- Enter the same code again to toggle it.
- Infinite health starts OFF after a fresh boot.
- Both players are protected; enemies still take damage.
- Hit reactions and knockback still occur.

Stage select - original game code

At the title screen, enter:

  IV, VI, II, II

Then choose LOAD to access stage selection. This original code is preserved
and works separately from the added infinite-health code.

IV, VI and II refer to the PC-FX controller's button labels. In an emulator,
use the controls mapped to those buttons.


TESTING AND KNOWN ISSUES

PC-FX emulation

During testing with the Beetle PC-FX core, the game played as intended,
with no observed skipping or stuttering. Movies, gameplay and subtitles
worked correctly in the emulator tests.

Core information and setup:
  https://docs.libretro.com/library/beetle_pc_fx/

Real PC-FX hardware

The PC-FX used for testing was connected to the television through an
RCA-to-HDMI converter. Gameplay played normally, and gameplay subtitles
lined up correctly with the spoken dialogue.

The observed problems were limited to movies: stuttering, skipping and
loss of synchronization. Original Japanese discs also showed movie
stuttering on the same setup.

The RCA-to-HDMI converter may have contributed to lag or playback issues,
but this has not been confirmed as the cause. Movie playback on real
hardware remains an unresolved testing issue.


UPGRADING AND SAVE STATES

Start from a fresh boot when switching from an earlier translated release.
Older emulator save states can restore older running game code and bring
back earlier subtitle or font behavior.

Create new save states after booting this release. This warning concerns
emulator save states, rather than the game's normal save function.


REPORTING PROBLEMS

Include the release version, character, stage, what happened, and the
subtitle line involved. Also include your emulator/core and version, or
your real PC-FX and display setup, and whether infinite health was enabled.

A screenshot or short video is helpful. For emulator issues, a save state
just before the problem can help reproduce it. Mention whether you started
from a fresh boot or loaded an older save state.
